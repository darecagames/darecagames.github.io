# Sugerencias para la web de Dareca Games

## Lo que ya funciona bien

- La web transmite una presencia seria y cuidada para un estudio indie.
- La estructura es clara: inicio, sobre mi, juegos y contacto.
- El hero tiene identidad gracias al logo grande y al slogan.
- El carrusel de Slimevolution aporta vida visual y hace que el juego sea el foco real.
- El selector ES/EN suma profesionalidad y ayuda si la web apunta a publico internacional.

## Mejoras recomendadas

- Cambiar el boton de Steam si todavia no existe una pagina real de Slimevolution. Ahora enlaza a la portada generica de Steam, lo que puede restar confianza. Mejor usar un estado tipo "Proximamente en Steam" o enlazar a la ficha real cuando este disponible.
- Hacer funcional la newsletter o eliminarla temporalmente. Ahora muestra un mensaje de exito, pero no guarda el email en ningun sitio.
- Anadir una descripcion mas concreta de Slimevolution: genero, objetivo, gancho jugable y por que deberia interesar al jugador.
- Unificar el tono de marca. Si Dareca Games es principalmente un desarrollador individual, conviene usar textos como "Mi Juego" o "Mis Proyectos" en vez de "Nuestros Juegos".
- Optimizar imagenes grandes antes de publicar. Varias pesan entre 1.5 MB y 6.5 MB, lo que puede afectar bastante a la carga.
- Darle mas personalidad propia de Slimevolution al estilo visual: elementos de slime, evolucion, biomas, criaturas o laboratorio, para que no parezca solo una landing tech/gamer generica.

## Prioridad sugerida

1. Corregir enlaces y llamadas a la accion.
2. Anadir una descripcion clara de Slimevolution.
3. Optimizar imagenes.
4. Conectar o retirar la newsletter.
5. Personalizar mas la direccion visual alrededor del juego.
